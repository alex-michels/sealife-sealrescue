# Design Brief — sealife / sealrescue (v1)

Одна токен-система, два режима. Уникально, но **lightweight и минималистично**.
Кириллица — обязательна (русский основной). Уникальный дизайн — только в публичных
фронтендах Next.js; админку Payload не перекрашиваем (внутренний инструмент).

> ⚠️ Не сваливаться в три AI-клише: (1) крем + контрастный сериф + терракота;
> (2) почти-чёрный фон + кислотный акцент; (3) бродшит с волосяными линейками.
> Наша опора — мир тюленей Северного/Балтийского моря: туман, балтийский тил,
> галечная шкура в крапинах, усы, буи, линия прилива.

---

## 1. Бренд и тон

- **sealife** — игривый, умиляющийся, с тюль-сленгом и тюль-жаргоном в микрокопии.
  (Бренд сайта — sealife. «Тюлента» — это сообщества VK/TG, источник аудитории, НЕ имя сайта.)
- **sealrescue** — серьёзный, спокойный, доверительный. Баланс тревоги и надежды.
- Оба сайта — один визуальный язык (для узнавания и воронки sealife ↔ sealrescue),
  но разная плотность, моушен и использование акцента.

---

## 2. Токены

### Палитра (4–6 именованных значений)
```
--fog       #E9ECEC   /* холодная туманная база (НЕ тёплый крем) */
--ink       #16262B   /* чернильно-сине-зелёный текст          */
--baltic    #1E5B5B   /* балтийский тил — primary               */
--pebble    #A99C8C   /* тёплый серо-бежевый, «тюленья шкура»   */
--buoy      #EE5A36   /* сигнальный коралл — ТОЛЬКО критичные CTA */
--sandbank  #E7D9C0   /* тёплый песок — фон карточек, дозированно */
```
- sealife: `--buoy` можно чуть смелее (акценты, бейджи), допускается мягкий
  игривый хайлайт. sealrescue: `--buoy` зарезервирован под ОДИН CTA «что делать».

### Типографика (обязательна кириллица)
```
Display  — округлый характерный, с restraint: Baloo 2 / Unbounded
Body     — гуманистический рублёный, родная кириллица: Onest / Golos Text
Mono     — данные, «штамп проверки», капшены: JetBrains Mono
```
- Грузим через `next/font` (self-host → нет внешних запросов, лучше для EU и скорости).
- Тип-шкала единая; sealife — дисплей громче и кинетичнее; sealrescue — тише, спокойнее.

### Радиусы / плотность
- sealife: заметное скругление (tactile, «умиляющийся»), щедрые отступы.
- sealrescue: умеренное скругление, больше воздуха, фото-forward.

---

## 3. Signature-элементы (по одному смелому на сайт)

- **sealife — «усатый» разделитель + маскот.** Вместо `<hr>` — тонкая линия,
  заканчивающаяся точками-крапинами (усы + крап шкуры). Дудл-тюлень с одной
  микрореакцией (моргает / «банан-поза» на hover). Крап как лёгкий фон-мотив.
- **sealrescue — «штамп проверки».** На каждой карточке центра моно-бейдж
  «Проверено: агент 12.06 · человек 14.06» + статус-точка. Это и доверие, и прямая
  визуализация полей `verifiedByAgentAt` / `verifiedByHumanAt` / `status`.
- Кастомные маркеры на карте по статусу (active/needs_check/link_broken).

---

## 4. Лейауты (концепты + вайрфреймы)

### sealife — bento-хаб («кусочки»)
Герой = характерный момент (кинетичный хэдлайн + маскот), дальше bento-плитки.
```
┌───────────────────────────────────────────────┐
│ 🦭 sealife     Тюленепедия  Игры  Новости   RU/EN│
├───────────────────────────────────────────────┤
│  ХЭДЛАЙН (округлый дисплей, лёгкая кинетика)     │
│  + дудл-маскот                                  │
├───────────────┬───────────────┬───────────────┤
│ ФАКТ ДНЯ      │ КВИЗ дня      │ МЕМ дня        │
├───────────────┼───────────────┴───────────────┤
│ МИНИ-ИГРА     │ ПОСЛЕДНЯЯ НОВОСТЬ              │
│ «угадай вид»  │                               │
├───────────────┴───────────────────────────────┤
│ →  Нашёл тюленя? Это серьёзно → sealrescue.info │
└───────────────────────────────────────────────┘
```

### sealrescue — emergency-first
Единственная задача главной: «я нашёл тюленя — что делать». Это и есть герой.
```
┌───────────────────────────────────────────────┐
│ sealrescue    Что делать  Центры  Новости   RU/EN│
├───────────────────────────────────────────────┤
│  [ фото: тюлень на берегу, спокойное ]          │
│  НАШЁЛ ТЮЛЕНЯ НА БЕРЕГУ?                         │
│  [ Что делать прямо сейчас → ]   ← --buoy CTA   │
├───────────────────────────────────────────────┤
│  Центры рядом      [ Карта | Список ]  ← toggle │
│  [chips: страна ▾  статус ▾  открыт сейчас ▾]   │
│  ┌ Центр N ─────── Проверено: агент 12.06 ✓ ─┐ │
│  │ tel(кликаб.) · сайт · соцсети   [маршрут →]│ │
│  └────────────────────────────────────────────┘ │
├───────────────────────────────────────────────┤
│  Новости спасения   ·  устал? нерпы → sealife   │
└───────────────────────────────────────────────┘
```

**Локатор (UX-практики):** тоггл карта/список; фильтр-чипы с числом результатов и
всегда видимыми активными фильтрами + «сбросить всё»; кликабельные телефоны;
маршрут в один тап; на мобиле фильтры — выезжающая шторка с живым обновлением.
Из статьи в каталог — дип-линк с предзаполненным фильтром (привязка к `crossLink`).

---

## 5. Моушен

- Сдержанно. Один оркестрованный момент на сайт (маскот машет на загрузке sealife /
  спокойное проявление фото на sealrescue). Остальное — микровзаимодействия на hover.
- Всегда уважать `prefers-reduced-motion`. Лишняя анимация читается как «AI-сгенерено».

---

## 6. Accessibility (WCAG 2.1 AA = и EU-требование EAA)

- Контраст AA для текста; `--buoy` на тёмном/светлом проверить отдельно.
- Видимый keyboard-focus; локатор и фильтры — навигация с клавиатуры.
- `alt` обязателен (поле уже required в `media`).
- Семантическая разметка, корректные заголовки, ARIA где нужно.

---

## 7. Lightweight / производительность (для соло-разработчика)

- Tailwind + CSS-переменные: токены выше → один конфиг, два режима (data-атрибут темы).
- Публичные сайты — кастомные и лёгкие; `shadcn/ui` допустим максимум для дашборда.
- SVG-дудлы (дёшево), без тяжёлых иллюстраций-растров на главной.
- Минимум JS; статическая генерация локализованных страниц; бюджет Core Web Vitals.
- Никаких внешних шрифтовых CDN (self-host через next/font) — скорость + EU.

---

## 8. Что НЕ делать

- Не перекрашивать админку Payload (это внутренний инструмент).
- Не брать шрифты без полноценной кириллицы.
- Не сваливаться в три AI-клише из шапки.
- Не перегружать анимацией; одно смелое место на сайт, остальное — тихо.
